RESEARCH

kernel
Windows drivers and kernel debugging. How the HAL, memory mapping and hypervisors behave in practice, not only on paper.
identity
Hardware IDs that can bind a licence to a machine without handing out its serial numbers, and that still hold up against spoofers.
crypto
PKI, distributed trust and protocol design.
reversing
Taking binaries apart with Ghidra and our own scripts to see what they actually do.

KEYED-HWID ↗ libraryRustApache-2.0 ● active
Hardware ID for Rust that never stores raw serials. Each component is hashed with a key, and a machine is still recognised after a disk or network card swap.
HWID Lab test harnessRustMIT / Apache-2.0 ○ in development
Tests whether KEYED-HWID notices spoofed, cloned or replayed hardware IDs. 17 scenarios, from a new SSD to a full spoof. Read-only: it never changes the system, altered values only exist in memory.

ABOUT

Sparx is a small group working on low-level security. We publish what we build so others can read it, check it and reuse it.

Found a bug or want to help? Open an issue on the repo it is about, or write to contact@sparx.foundation. A person reads it.
